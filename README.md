# PeerEvaluationSys

A minimal browser-based Peer Evaluation System for startup teams.

## Features

- Add team members
- Submit weekly peer evaluations on 4 benchmarks:
  - Deliverables
  - Commitment
  - Cooperation
  - Initiative
- Calculate weekly score per member as the average of peer ratings
- Track completion toward the 6-peer target
- Archive evaluation data locally in the browser (`localStorage`)

## Run locally

Open `index.html` in a browser.
